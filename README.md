# Tornique Multi Speciality Clinic — Landing Page

Landing page for Tornique Multi Speciality Clinic and Sri Lakshmi Medicals
(attached pharmacy), M.B. Complex, Boganahalli Main Road, Panathur,
Bengaluru.

Plain HTML/CSS/JS, no build step — `index.html` is the entry point.
Same design system as the Shweta Clinic and Dr. Sumanjita Bora sites,
recolored to violet/purple, with reviews moved ahead of services.

## Local preview

```
python3 -m http.server 8000
```

Then open http://localhost:8000
